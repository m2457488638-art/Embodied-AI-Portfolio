## 主页展示方式

- G1 视频使用可点击封面和 MP4 文件链接。
- SSDP3 架构图和 Isaac Sim 场景截图直接显示在相应项目下。
- Go2 项目位于桌面 Isaac Sim 场景项目前，使用可点击视频封面，并直接展示训练环境截图。
- 上传或更新时保持根目录 `README.md` 和本目录的相对层级。
- 日后替换视频时，检查链接与封面是否同步更新。
